# KIVO Launcher

KIVO Launcher is an independent, non-commercial Minecraft launcher based on the open-source PCL project. It is currently in early development. This repository currently contains project information; the launcher source code has not yet been published here.

If approved, the CurseForge API will be used in the launcher to search Minecraft mods and modpacks and retrieve items selected by users. We will use an API key issued for this project, keep it out of the public repository, respect mod authors' distribution permissions, and comply with the API terms.

The project has no ads, paid features, or sales. KIVO Launcher is not affiliated with CurseForge, Overwolf, or the PCL developers.
